# herdr-multi-agent

Skills for coordinating multiple coding agents running in herdr panes.

[herdr](https://github.com/herdrdev/herdr) is the terminal multiplexer these skills target. The upstream herdr skill lives at [skills/herdr](https://github.com/herdrdev/herdr/tree/master/skills/herdr).

## Contents

- `skills/example-workflow/` — placeholder skill. Replace it with real workflows.

## Local development

From a Claude Code session, add the marketplace from this repo and install the plugin:

```
/plugin marketplace add /Users/kerry.hatcher/projects/hatek/multi-agent
/plugin install herdr-multi-agent@multi-agent
```
